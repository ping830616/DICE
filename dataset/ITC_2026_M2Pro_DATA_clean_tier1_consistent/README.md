# ITC_2026_M2Pro_DATA_clean_tier1_consistent

This is the release-ready, harmonized DICE dataset for Apple macOS using the profile:

- Tier-0 (`psutil`)
- Tier-1-alt (`macmon`/fallback path)
- Tier-2 (`xctrace`)

## Scope

- Cases: 24 (`WORKLOAD__STRESSOR`)
- Sampling: 5 Hz
- Rows per case CSV: 5000 (5001 lines including header)
- Included groups:
  - `tier0/*/tier0_full_5hz.csv`
  - `tier1_alt/*/tier1_alt_core_5hz.csv`
  - `tier1_alt/*/tier1_alt_full_5hz.csv`
  - `tier2/*/tier2_core_5hz.csv`
  - `tier2/*/tier2_full_5hz.csv`

## Harmonization Policy

This folder is generated by `tools/ensure_no_nan_dataset.py` with:

- `--tier1_mode alt`
- `--keep_all_nan_columns`
- `--min_coverage_ratio 0.0`
- `--fallback_fill global_median`

So every case has a consistent schema and no NaN cells. Columns unsupported by platform sensors are retained and imputed.

See `no_nan_report.json` for per-group coverage and imputation details.
